# How to run locally
  1. Install Node JS (https://nodejs.org/en)
  2. Download the .zip of this project (Click the green button that says <> Code on this page and then click download zip)
  3. Unzip the folder. 
  4. Open the command panel and drag the project folder into it
     /or navigate to the folder using cd [FILEPATH]
  5. Once in the folder type npm install for the initial set up
  6. Run the command npm run dev to host the project locally and be able to see it in your browser
